## Features adopted in Lab.Works

| Pattern | Seen on | Where it appears in Lab.Works |
|---|---|---|
| Split homepage aimed at both sides ("Looking for a lab?" / "Need projects?") | Contract Laboratory | Hero "What brings you here?" |
| Multi-step request for quotation (RFQ) with a progress bar | Scientist.com, Contract Laboratory | 4-step quote wizard with autosave |
| Audience switcher | Labcorp, Quest | Hero card |
| Sponsored "Featured" slots | Biocompare, Labcompare, LabX | Featured labs, directory |
| Lab-listing tiers (free and paid) | Contract Laboratory | List Your Lab plans |
| Calculator page template: widget, formula, example, FAQ, related tools | Omni Calculator | Every tool page |
| Search box as the main entry point | Calculator.net, Quest | Hero search with live index |
| "Donate" in the main navigation, 501(c)(3)-style transparency | Science Buddies | Support page with fund allocation |
| Awards with public voting | SelectScience | Science Challenge with People's Choice |
| Grant challenges and transparent fees | Experiment.com | Contests and sponsor tiers |
| Job alerts and CV matching | Nature Careers, Science Careers | Job alert builder |
| Newsletter with topic checkboxes | Scientist.com, Addgene | Footer newsletter |
| Accreditation badges and verification | testing.com, Eurofins | Accreditation-body lookup, vetting steps |
| Editorial policy and review bylines | Omni Calculator, testing.com | About page (editorial policy), guide bylines |
| Media kit and sponsored content | Lab Manager, Bitesize Bio | Advertise page |
